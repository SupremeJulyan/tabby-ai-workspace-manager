# 独立插件边界

Tabby 提供 SSH 连接、主机密钥确认、认证、跳板机、本地/远程终端、标签与分屏。
ARW 插件复用 SSH 标签持有的会话，通过独立 exec 通道与 SFTP 完成操作，不新建认证链路。

optional-sftp.ts 按会话及底层客户端缓存 SFTP 能力探测，并对初始化设置 10 秒上限。sftp-text.ts 使用 SFTP 读取与原地保存远程文本；打开时记录文件大小和修改时间，保存前仅用 stat 比较这两个字段，不计算内容哈希或重新读取正文。保存后返回新的大小和修改时间，沿用 WorkspaceText.hash / expectedHash 字段作为不透明版本标识。侧栏的读取、预览、目录列举及 SFTP 保存不启动 SSH 路径校验；arw-cli/workspace-files.ts 在 CLI 入口限制写入范围；读取、目录列举、搜索和下载来源按账户权限访问，不限制在工作区内。普通文件保留 inode、权限、ACL 和扩展属性，新文件写入内容前设置为 0600；setuid/setgid 位由操作系统决定，不主动恢复或核对。保存前权限记录用于断线后的显式核对，失败时由 SaveConfirmation 保留异常标记。

SFTP 不可用时，shell-files.ts 提供 NUL 格式目录列举（最多 2001 项）和有界 Base64 文本读取。remote-save.ts 使用已认证 SSH 连接上的一个 exec 通道比较文件大小和修改时间，通过就绪帧后接收标准输入正文并原地写入，不依赖 sha256sum。executeChannel 等待就绪帧后分块发送正文，以退出状态确认完成。目录集成脚本也可通过 SSH 写入私有临时目录，交互终端执行短 source 指令。

插件构建使用 npm 发布的 Tabby 类型定义，不访问相邻源码目录。TypeScript 先生成 Angular 依赖注入所需的装饰器元数据，再由 esbuild 将 ARW 核心打入 CommonJS 插件。
Angular、Tabby、RxJS 与 russh 由宿主提供，不能随插件重复打包。

Git relay 仅使用本地临时裸仓库及对象缓存；远程工作目录仍是唯一工作副本。
同一会话/目录的中转任务串行；工作区与任务目标在启动时固定。
没有 SSH exit-status 上层事件时，独立非 PTY shell 返回随机结果标记，缺失结果会报未知状态。

后续：真实桌面加载验证、会话与取消集成测试、CLI 生命周期及多实例发现、Agent 活动事件。

发布的 tabby-ssh 包中，SSHTabComponent 存在于运行时导出，但入口类型声明遗漏它。插件只从该包 typings 子路径导入类型，并从运行时命名空间取构造器；不导入宿主内部源码、不打包第二份 SSH 模块。

## 插件结构约定

参考 Tabby 官方 HACKING.md 的 Plugins 部分与 tabby-clippy 示例：
- https://github.com/Eugeny/tabby/blob/master/HACKING.md
- https://github.com/Eugeny/tabby-clippy

`src/index.ts` 只负责模块注册与启动兼容检查，只默认导出 NgModule。
`services/workspaces.service.ts` 管理目录绑定与失效；`services/git-tasks.service.ts` 管理中转任务、并发、取消与进度。
`providers/context-menu.provider.ts` 使用宿主的 multi provider 扩展菜单。
`adapters/ssh-compat.ts` 集中隔离运行时构造器和发布包类型声明差异；`adapters/transport.ts` 负责会话传输。
`api.ts` 定义内部共用的数据类型。

没有自定义 Angular 模板时，继续使用 tsc + esbuild；先由 tsc 生成 DI 元数据，再打包，避免 esbuild 单独转译丢失元数据。
这不是官方 Webpack 模板的完整替代方案。新增 Angular 页面、外部模板或 SCSS 前，需要引入对应模板编译/资源处理并验证。

宿主依赖通过 peerDependencies 声明并 external，标记 optional 用于阻止 npm 在用户插件目录自动安装第二份宿主；运行时仍需兼容的 Tabby SSH 插件。
发布前 prepublishOnly 会运行工作区的构建和测试。当前验证包括发布包类型检查、模拟宿主加载、Git 集成测试及空目录安装，真实服务器 SSH 联调尚未完成。

## 目录转发开关

`DirectoryForwardingDecorator` 通过宿主 TerminalDecorator 扩展点观察原生 SSH 标签，将开关放入 SFTP 目录栏。原生 SFTP 暂无公开 header-button provider，因此 DOM 适配集中在该 decorator，不修改宿主原型或安装文件。
`ForwardingService` 管理显式目录、SSH 会话引用、启动竞争和断开清理。目录切换、关闭 SFTP 面板或标签都会撤销端点；不会把既有 Agent 请求隐式路由到新目录。
`ForwardingServer` 保留 JSON HTTP 请求格式，但通过操作系统 IPC 通信：Linux/macOS 使用 Unix Domain Socket，Windows 使用本机命名管道，不监听 TCP 端口。每个开启目录独立端点；连接文件采用 version 2，保存 socketPath 与令牌，凭据放在 Authorization 请求头中。CLI 通过 node:http 的 socketPath 发起请求，不经过 DNS 或 HTTP 代理，也不回退到旧 TCP 地址。

Unix Socket 位于随机创建的私有临时目录中，目录权限 0700、Socket 权限 0600；路径过长时使用 /tmp 下的短路径。Windows 管道使用本机固定前缀及随机 UUID，并继续校验随机令牌。启动与关闭串行化，停用中止执行信号、关闭连接并清理 Socket 目录。旧版连接文件明确提示重启 Tabby，不会偷偷使用 TCP；工作区索引格式及 --id 用法不变。
服务提供列目录、UTF-8 读写和远程命令；文本上限 500 MiB。命令拥有 SSH 账号权限，cwd 不是安全沙箱。

2026-10-24 在真实 Tabby 1.0.238 中验证 decorator/服务注入、目录按钮、开关、CLI 写入和切换目录后停止。文件后端为内存 SFTP fixture，真实 SSH 端到端验证仍待完成。

## CLI-only 连接

目录开关生成权限为 0600 的临时连接文件，按钮复制 Node CLI 命令。关闭、切换、断开时删除文件并撤销端点。
本地转发采用 `{name, arguments}` 请求和 `{result}` 响应格式；请求必须包含当前 workspaceId。
SDK 与 Zod 依赖已移除，插件不提供 MCP 接口。CLI 可执行文件随包发布；不覆盖现有全局 arw 命令或 VS Code 的连接记录。

每个仓库还提供提交记录和本地分支两个只读信息页。提交记录读取最近 50 条提交，点击后以只读差异标签显示提交说明、作者、时间及补丁；合并提交按首父提交显示，不执行外部 diff/textconv。分支页显示当前符号引用或游离 HEAD，只能切换已有本地分支，不自动创建、删除、拉取或推送。存在已跟踪改动时切换前要求确认，Git 拒绝覆盖时提示先提交或还原，不自动 stash；未跟踪文件保留。信息读取与状态刷新并发进行，失败不会隐藏已有的变更状态。

## 三模块工作区

运行时仍为一个独立 Tabby 插件包，内部按 arw-tree、arw-cli、arw-ai-cli 划分。共用的 Workspace 对象不可变地绑定 kind/root/host/id 和文件／命令后端。
WorkspaceRegistry 使用 TerminalDecorator 注册本地或 SSH 标签，监听 focused、sessionChanged 及 OSC cwdReported。路径变化创建新快照；编辑器和 AI 会话保留旧快照。远程尚无路径上报时自动复用 Tabby SFTP 浏览目录；尚未选择目录时解析并验证 SSH 登录初始目录，避免默认打开 `/`，标记路径来源；首次真实路径上报会替换该目录。
目录树是 Angular 组件，节点按需加载并用版本号丢弃旧目录的异步结果。Git 视图独立解析仓库根目录，避免在子目录下错误拼接 porcelain 路径。
Git 源码管理的顶部提供提交说明框；变更按仓库分组，可逐项或批量调用 RemoteGit 的 stage/unstage。提交只使用索引并沿用远端 Git 配置与提交身份，不自动暂存工作区内容。操作后重新读取状态，提示按仓库根目录暂时保留，切换该仓库或开始下一次操作时清除。远程和本地仓库都通过 Workspace.run 执行命令，不把 SSH 仓库误当作本地路径。

暂存、取消暂存、还原和提交后仅重新读取目标仓库的 status，原地更新分组，不重新发现所有仓库或清空列表；仓库、分组和路径提供稳定 trackBy，保留展开状态和提交草稿。单文件或批量还原仅处理未暂存更改，先通过宿主消息框确认：跟踪文件从索引还原，保留已暂存内容；未跟踪文件仅删除明确选中的路径；冲突文件拒绝直接还原。暂存重命名后的文件只还原当前路径，避免错误地还原已从索引移除的旧路径。

差异视图设计参考开源 Tabby 插件 jghwang2/tabby-agentdeck 的 src/gitDiff.ts 和 src/gitCommit.ts：以真实 Git 输出为依据，纯解析模型与执行操作分离，并按 hunk 声明行数解析正文，避免文件内容伪装成 diff 头。ARW 独立实现并排/统一视图、行号、增删配色和差异块切换；未跟踪文本以空文件为基线，二进制和合并冲突分别提示。显示暂存差异时比较 HEAD 与索引，未暂存差异比较索引与工作树。Git diff 禁用外部 diff/textconv，文本通过 Angular 插值展示，不执行文件内容；超过 20000 行时拒绝构建庞大的视图。参考插件不是运行时依赖，也不会被安装。
本地编辑器使用内容哈希检查外部修改；远程编辑器仅比较文件大小和修改时间。保存原地写入，不替换文件。检查与写入之间仍存在竞态，不是分布式文件锁；相同大小且修改时间未变化的远端修改不会被识别。可确认的保存前冲突使用 FileConflictError 标识，编辑器询问是否覆盖；肯定答复才不带旧版本重写，否定答复重新读取并显示最新内容。普通保存失败及未确认写入不走此覆盖流程。Markdown 默认进入编辑器，预览开关在同一标签页渲染当前缓冲区及相对图片，不保存或重新读取正文。
SidebarService 负责唯一宿主 DOM 插入点，目录、编辑与 AI 界面均走 Angular。侧栏默认 300px，右边缘可拖动或使用方向键调整（240–520px），并记忆宽度；与其他侧栏插件并存时可能占用额外空间。
顶部定位箭头保留为独立的单次跟随操作，读取交互终端当前 pwd 后刷新目录树；它不切换终端模式，也不会在后续 `cd` 时自动重复跟随。普通刷新只更新已浏览的目录；开启终端模式时会同步原交互终端的 pwd。
字体通过 ConfigService 读取当前 `terminal.font`、`fallbackFont`、`fontSize` 与 `linePadding`，变化时同步更新侧栏和文件标签页共享的 CSS 变量。侧栏基础字号为终端字号减 2px，原有紧凑字号按同一差值相对缩放；文件正文与差异沿用终端字体。颜色继续使用宿主 `--theme-bg`/`--theme-fg` 与主题变量，不维护独立配色。
远程 AI 的 cwd 使用稳定本地占位目录，位于 Tabby 配置目录的 awm/agent-cwd 下。第一级目录由 SSH 主机 IP 和端口组成：IPv4 按四个八位组转为八个十六进制字符，端口转为十六进制，两者用连字符分隔（例如 10.44.9.4:22 为 0a2c0904-16）；非 IPv4 主机名按 UTF-8 字节转为十六进制。第二级目录是规范化远程绝对路径的 SHA-256 前 16 位。该布局只由端点和远程路径决定，同一组合稳定复用 cwd。占位目录持久保存远程映射和简短 AGENTS.md 操作指引，不生成 CLAUDE.md，不包含项目副本，不生成或依赖 Skill。新建会话的 CLI 配置、令牌和启动器放在各 AI 会话独有的临时目录，通过环境变量注入，不会被后续启动覆盖。AI 标签关闭时清理临时目录，释放服务与 SSH 引用，保留占位目录；原终端切换目录不影响其绑定。
CLI 不再提供 Skill 安装命令；本地项目不会自动写入指令文件。DeepSeek TUI 的具体可执行文件由用户首次配置。

侧栏界面参考 Better Sidebar 的紧凑分区方式：顶部工作区树和连接信息、文件/Git/AI 活动视图、筛选栏、树节点图标和底部 CLI 操作。AI 操作位于已保存工作区条目上。模板和样式独立位于 tree.view.ts，未复制参考插件源码。

AI 活动参考 SAFS VS Code 插件的类型/状态筛选和活动时间线。ForwardingServer 的已认证请求携带来源远程终端的独立标识，AgentActivityStore 记录该标识，侧栏合并当前顶层标签页中各来源终端的活动；同一标签页的多个 AI 终端共享列表，每项显式标明工作区，不同标签页相互隔离。AI 分屏继承原远程终端的标识。本地终端不显示 AI 活动入口。不同终端不复用彼此的 AI 转发连接；共享保存条目的原转发仍归原来源终端所有。记录执行中、成功、失败和策略拦截，包含工具、脱敏的命令/路径、主机、工作区、时间、耗时及退出码；非零退出码按失败显示。面板不记录文件正文、命令输出、AI 对话或本地直接执行的命令，也不推测 AI 身份。详情采用 Angular 文本插值，稳定 ID 保持展开状态；订阅随面板销毁解除。清空需要确认，只删除已完成的内存记录，保留执行中的请求和独立的安全审计日志。重启 Tabby 后活动列表清空，安全审计仍保留在 audit.jsonl。

AI 启动后在当前工作区终端所在的 Tabby 原生分屏中打开，并放在源终端右侧；若源终端尚未分屏，则复用 AI 新标签的分屏并将源终端放到左侧。这里使用宿主 SplitTabComponent，而不是把终端 DOM 另行挂到侧栏，以保留 Tabby 的焦点、尺寸拖动和标签恢复行为。
AI 的工作区绑定在移动分屏前建立，独立于 TerminalDecorator 的挂载记录保存，直到终端销毁才清除。装饰器重新挂载时恢复绑定，避免点击 AI 窗格或本地 cwd 上报把远程目录树替换为占位目录。

保存的工作区位于 ARW 标题下的树形列表。顶部加号保存当前浏览目录的绝对路径，不改变当前终端目录；ProjectStore 将本地条目和各 SSH 主机/端口/账号的条目分别持久化到 Tabby 配置。浏览后端与终端检测快照分离，选中保存条目后，文件读取、Git 和 AI 使用该条目的根目录；无论是否处于终端模式，只有显式点击定位箭头才重新使用终端当前目录。每个条目提供 AI 按钮，原底部 AI 栏移除。
标题栏的终端模式是侧栏内的临时会话状态，不写入配置；开启后隐藏保存列表，展示唯一一个当前浏览目录的临时条目，并禁止添加和移除工作区。开启模式时同步原交互终端目录；普通刷新和重新聚焦标签不读取终端工作目录。Agent 命令经现有 PTY 注入，使用其当前用户和导出的环境，通过随机标记捕获输出与退出码，stdout/stderr 合并。每个终端串行执行，关闭模式、取消、超时、连接变化或退出均结束捕获，禁止自动降级到独立 SSH exec。终端模式只允许命令执行及保留输出续读，结构化文件、搜索、传输与批处理拒绝执行；关闭模式恢复普通转发。显式点击定位箭头时才读取原交互终端上报的工作目录；缺少上报时提示启用路径检测，保留已有浏览位置。关闭模式恢复保存列表，不删除条目或撤销已有转发。

AI CLI 配置由宿主 tabby-settings 的 SettingsTabProvider 注册独立 ai-workspace-manager 设置页，不依赖 ConfigProvider 的非标准 schema 字段。设置页将可执行文件和逐行参数保存到 arw.agent；启动时读取最新设置，工作区绑定与远程占位目录机制保持不变。tabby-settings 与其他宿主模块一样 external，不随插件打包。

ProjectStore 在初始化、添加和移除后仅将保存的远程工作区导出到配置目录下的 omw/workspaces.json，本地条目仍保留在侧栏和 Tabby 配置中。导出使用串行写入、0600 临时文件与原子替换，索引含工作区元数据、连接身份和私有连接文件路径，不含 kind 字段或活动连接令牌。读取旧索引时过滤本地条目并移除 kind 字段。常规 AI 启动不再注入 ARW_CONFIG；arw workspaces 直接读取此索引，其他操作按 --id ID 查找对应连接，因此一个 AI 会话可以显式操作多个已转发远程工作区，不保持固定绑定。CLI 已移除显式连接配置参数；ARW_CONFIG 只保留给旧启动 API 的私有连接兼容路径。--saved 仍可强制从保存目录查询远程列表。

保存条目即授权开启该根目录的转发，不再提供侧栏手动开关。ProjectStore 按条目 ID 独立持有 ForwardingServer、私有连接文件和 SSH 引用，文件与命令后端绑定创建时的目录快照。删除时先从保存列表移除以防并发恢复，再撤销端点、取消命令、清理连接文件和释放引用；正在启动的条目被删除后也不得发布端点。切换目录、标签或关闭 AI 标签不撤销其他条目的转发。

本地保存条目在插件初始化时恢复，远程条目在对应主机/端口/账号的终端加载时恢复，SSH 断开时撤销该会话的端点并保留离线条目。工作区 AI 按钮复用条目的转发配置，删除条目后已有 AI 的 CLI 请求失败。兼容的旧启动 API 仍保留独立临时连接路径，但不用于工作区条目按钮。

Git 发现将标准 not-a-repository 视为正常空结果；权限、安全目录和缺失 Git 等其他故障仍保留错误。仅发现当前范围内的仓库，侧栏扫描最多 2 层/60 目录/10 仓库/5000 条目，单目录最多读取 2000 条目，总发现时间最多 3 秒，支持 .git 文件型 worktree，不跟随目录符号链接。各仓库独立保存展开状态与文件后端，防止同名文件或本地中转操作落入其他项目。

缺少远程路径时保留已认证的 SSH 会话元数据，区分“未连接”和“已连接但等待路径”。用户显式点击后，通过原交互式 shell 的 sendInput 安装会话级 Bash/Zsh/Fish hook；不另开 exec 查询 pwd、不修改远程配置文件、不在连接时自动注入命令。检测到全屏程序时拒绝注入，等待路径超时提供重试提示。实际 shell 测试验证 OSC 转义、原提示符保留及重复注册。

Git 发现支持并发、AbortSignal 与逐仓库回调。侧栏以 2 个目录和 2 个状态请求为上限，发现项目即显示；默认不递归已识别仓库内部，降低高延迟 SFTP 上的请求数量，嵌套项目可进入对应目录再扫描。

交互式 shell 的跟随依赖路径上报。集成脚本经现有 SSH/SFTP 会话写入私有临时目录，终端仅执行简短 source 命令；脚本在成功上报、超时、切换或销毁后清理，远端启动文件不被修改。只依赖新 exec 通道的 pwd 无法读取已有交互 shell 的 cwd。

## 转发安全策略

`security/high-risk-commands.ts` 和 `security/remote-command-boundary.ts` 迁移 SAFS 的高危规则、删除目标分析及显式命令边界检查。ForwardingServer 在执行任何 CLI 命令前强制应用默认拒绝策略，调用方不能通过请求参数指定来源或放行规则；命令上限为 64 KiB，并扫描可识别的内嵌 shell。工作区持久转发、AI 私有转发与兼容的目录树转发复用这一入口。

RemotePathGuard 使用受 shell 引号保护的远程 realpath 校验根目录和目标，读和列目录要求目标存在。remote-save.ts 对写入校验真实根目录及目标路径，允许新文件，拒绝最终符号链接和硬链接；父目录的真实目标须在工作区根目录内。路径和元数据检查与写入之间仍有并发修改的窗口。远程 Workspace 提供 validateCommand，转发层调用它以检查可识别命令目标的符号链接；内部 Git 操作与用户手动终端使用各自的执行入口。

ForwardingServer 将每个已认证调用的请求 ID、工作区 ID、操作和结果写入配置目录中的 omw/audit.jsonl。日志串行追加、限制权限、拒绝符号链接日志文件，约 1 MiB 轮换且保留一个备份。执行前的审计失败会阻止请求，执行后的审计失败会返回错误，此时操作可能已经生效，不应自动重试变更。日志不保存结构化文件正文或输出，命令和路径按已知敏感字段脱敏。命令和路径策略拒绝返回 POLICY_DENIED；网络或执行故障不伪装成策略放行。

静态 shell 分析不覆盖任意语言程序、间接系统调用和所有 shell 语法，realpath 检查与随后的文件访问也存在并发路径替换风险；这里移植的是 SAFS 防误操作策略，不是 chroot、容器或强制访问控制。主机密钥和 SSH 登录认证继续由 Tabby 宿主承担，不另建放宽验证的 SSH 连接。


### CLI 文件复制

`arw upload [-r] LOCAL REMOTE --id ID` 与 `arw download [-r] REMOTE LOCAL --id ID` 分别上传、下载，无需路径前缀。CLI 负责本地文件句柄及目录遍历；转发端仅接收工作区内远端路径、临时传输 ID 和最多 256 KiB 的分块数据，不访问用户提供的本地路径。远端由 `adapters/sftp-copy.ts` 通过当前 SSH 会话的 SFTPSession 读写，参照 Tabby 官方 `session/sftp.ts` 的 handle.read/write 循环及临时文件重命名流程。桥接请求中分块数据以 base64 编码，不调用远端 shell 传输正文，也不将整个文件载入内存。

每个转发后端独立保存传输句柄，最多同时 16 个，空闲两分钟清理；完成、取消、失败及转发撤销均关闭句柄并清理未发布的临时上传。临时文件名随机生成；上传发布前再次验证真实路径并检查目标是否存在。下载在 CLI 侧通过同目录临时文件与排他发布保留已有目标。目录复制按顺序执行，后续失败不回滚已完成的条目。普通文件读写的 500 MiB 文本限制不适用于上传和下载。


手动开启的临时转发独立注册到 omw/active-workspaces，不受 ProjectStore 保存索引重写影响。CLI 自动合并保存索引与仍在运行的宿主进程注册项，忽略已退出进程的条目。关闭转发移除注册，不需要复制或指定私有连接文件。


### CLI Git 中转

CLI 的 `git-pull` / `git-push` 通过专用转发操作复用侧栏的 relayGit，使用本机 Git 网络和凭据。支持工作区内的可选项目路径，拒绝越界路径和位于工作区上级的仓库；三个转发入口均绑定同一实现，并与侧栏 Git 中转共享会话及仓库锁。终端模式不提供此操作。

### Git 与目录刷新范围

Git 扫描以当前目录栏的路径为起点，而非登录时的初始目录；解析出的仓库根目录仍用于执行 Git，以保证变更路径正确。暂存、取消暂存、提交、还原、切换分支和本地拉取/推送仅更新目标仓库状态，按需要重新读取该仓库的历史与分支，不重建文件目录树或重新发现全部仓库。Git 标签只展示已有结果，初次进入也不自动扫描；显式 Git 刷新保留仓库对象、折叠、信息页和提交草稿。

普通文件刷新重新读取当前浏览路径及已展开的目录，保留 relativePath 和展开状态，不重置回工作区根目录。浏览状态按来源终端标签保存；共享同一 SSH 传输连接的两个标签各自记忆目录，AI 分屏与其来源终端共享浏览位置；在同一会话的 SSH 与 AI 终端之间切换不会改变当前浏览目录，切到其他会话后返回也恢复原位置。重新连接同一标签时，保留浏览路径并将后端重新绑定到新 SSH 会话。切换会话或浏览目录后，旧异步请求不能覆盖新视图。


### 侧栏 SFTP 下载

远程文件树的 contextmenu 通过 PlatformService.popupContextMenu 提供文件与目录下载项。菜单回调捕获打开菜单时的远端会话、浏览后端和节点路径，后续标签切换不会改变下载目标；下载不会刷新目录树。文件使用 PlatformService.startDownload 与 SFTPSession.download，目录直接调用宿主导出的 SFTPPanelComponent.downloadFolder，复用官方目录选择、递归下载、取消与传输进度界面，不挂载或导航官方 SFTP 面板。

sftp-download 适配器保留下载期间的 SSH 引用，在断连时取消传输，完成后释放引用。文件与目录路径通过真实路径检查，目录枚举跳过符号链接，校验文件名后交给原生目录传输处理本地保存路径。兼容声明较旧而运行时支持目录下载的 Tabby；实际宿主缺少该 API 时明确报告不支持，不改用 shell 打包传输。


### Git 扫描限制与取消

后台 Git 扫描复用已发现的仓库缓存，重复刷新不启动并发扫描。扫描超出目录、条目或时间预算时保留已发现结果并提示进入具体项目目录。目录枚举不对整个大目录排序：本地使用流式 opendir，远端使用有输出条目上限的 find。状态和历史等后台 Git 读取每条命令限时 3 秒、输出上限 256 KiB；状态超过 1000 项时不渲染变更列表。文件事件驱动的 Git 刷新至少间隔 5 秒，每个仓库只查询一次状态。

本地监听仅覆盖当前查看的目录和仓库 Git 元数据目录，最多 32 个非递归监听器，不扫描未展开的子树；因此未查看的深层文件变更可能需要手动刷新。远端目录快照最多检测 32 个目录，大目录停止后台检测并显示提示。

取消操作中止扫描专属 AbortController、清除加载状态并保留已发现的仓库，不取消独立的暂存、提交等修改操作。取消后可重新扫描。Git 命令、路径校验和无 SFTP 时的 shell 目录读取均接收扫描信号；原生 SFTP 目录请求无法单独撤销时，扫描立即停止等待，其迟到结果会被丢弃，且不再启动后续目录工作。


### 空 Git 视图的初始化与克隆

只有手动扫描完整结束、没有仓库或扫描错误且当前源是已连接 SSH 终端时，才显示创建入口；初始未扫描、取消和目录切换均不会误显示。表单收集用户名、邮箱、远程链接，克隆另可指定当前目录下的新文件夹名称。初始化在远程当前目录执行 git init，配置仓库本地 user.name、user.email、origin 及 main 的上游，不更改全局配置、不删除现有文件、不创建提交。执行前再次确认目录不属于已有仓库。

克隆由 GitTasksService 复用当前 SSH 会话、锁与任务取消能力。git-bootstrap 在本地私有临时目录执行 bare clone，沿用本机凭据和网络；通过 Git bundle 将分支与标签传到远程私有暂存目录，远端只从 bundle 导入并检出默认分支，原始网络链接写回 origin。目标路径复核且不存在时才发布到新目录；失败或取消清理临时目录，不删除已有目标。空上游仓库不生成空 bundle。LFS 文件仍为 Git 中保存的指针，远端检出时不请求 LFS 网络内容。

成功后只读取已知新仓库的状态、分支和历史，不重新发现其他目录，不跳转浏览位置。表单中的目标目录固定显示，切换目录后不会将操作误投递到新目录；操作持续期间保留 SSH 引用，关闭连接或取消会中止任务。


### 文件预览

文件树按扩展名分派到独立预览标签，继续持有原工作区及 SSH 引用；不会改变侧栏路径。Workspace.readBytes 从本机文件句柄或原生 SFTP 有界读取，校验大小及中断，finally 关闭句柄。文本预览仅在缺少 SFTP 时使用已有 read 回退；关闭标签会取消读取并释放引用。

PDF.js 作为独立 pdf-preview.cjs 懒加载，worker、CMap、字体、WASM 与 ICC 资源随包发布，不依赖 CDN。浏览器使用 Blob 模块 worker；资产读取使用受限本机文件路径。页面顺序渲染，限制 canvas 像素并在关闭和重载时释放任务。TIFF 通过 UTIF 解码首帧并检查尺寸。

Markdown 使用 Marked 生成 HTML 后仍交给 Angular 消毒；原始 HTML 转义，链接限制协议，外部图片不请求，相对图片必须位于当前工作区并受数量与总字节限制。CSV 支持引号、跨行字段和转义，限制行列并分页，模板使用文本插值显示字段。

### AI 终端恢复

WorkspaceTerminalDecorator 在 Tabby 初始化本机 PTY 前识别 ARW 终端。新建终端通过仅本次启动有效的环境标记保留原始命令；getRecoveryToken 生成的原生恢复信息移除该标记和临时 ARW_CONFIG，将 PATH 指向配置目录内持久 CLI 包装器，并固定原工作目录。恢复时 Codex 使用 resume --last，Claude 使用 --continue；显式恢复参数不重复添加，不给未知 CLI 推断参数。继续使用 Tabby 原生恢复 token 和 PTY 重连机制。

旧版 ARW 终端没有新建标记，恢复后也会在进程启动前转换续接参数。远程占位目录通过所属配置路径和 workspace.json 验证，启动时刷新简短 AGENTS.md。转发连接继续由工作区目录管理，恢复信息不保存临时连接凭据。


### SSH 会话更换与转发绑定

转发条目记录来源终端、SSH 会话和认证客户端，来源终端重连后重新绑定，不能仅凭旧会话 open 标记复用。恢复侧栏记忆目录以及切回 AI 标签时也同步该绑定，保留工作区 ID 和远程根目录；身份不匹配时等待原来源连接。切到同主机另一条正常终端连接时保留健康转发，不中断执行中的命令。旧连接的迟到关闭通知不能撤销新连接；服务销毁后，等待关闭完成的旧请求不能重新创建转发。不会自动重试远程命令或修改操作。


### 工作区转发指示

ProjectStore 通过 changed 事件通知侧栏刷新状态，不重新加载文件树或扫描 Git。状态包括 saved、starting、forwarding、error；启动失败、请求失败和 SSH 断连保留最近 5 条脱敏错误记录，每条至多 8000 字符，包含时间、操作名与异常堆栈。工作区名称和状态图标的原生 title 提供悬停详情。正常转发使用绿色脉冲，启动时旋转，失败使用静态警告及行标记；遵循 prefers-reduced-motion。

ForwardingServer 在实际操作完成后报告结果；仅查询工作区、当前文件、缓存输出不会清除错误。批处理由内部实际操作报告状态，外层完成不会覆盖失败；策略拒绝及普通命令非零退出码不会误报传输失败。状态仅描述转发和最近请求，不是持续 SSH 健康探测，也不会发起自动重试。


### 启动与恢复参数

agent.args 继续保存启动参数，新增 agent.resumeArgs 保存完整恢复参数数组。未设置或 null 表示兼容旧配置的自动推断；显式空数组表示恢复时无参数。设置页面预填旧配置的兼容恢复参数，保存后两组参数独立使用。恢复装饰器仅在配置命令与该终端命令一致时采用恢复参数，避免更换全局 CLI 命令后将新工具参数套给旧终端；不同命令保留已保存的恢复信息。新建终端不使用恢复参数，原有工作目录、凭据清理与标签恢复机制不变。
